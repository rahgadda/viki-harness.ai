# Viki

## Overview

**Viki** is a python based harness which aims to provide a UI based agent framework for creating agents that perform specific tasks through two approaches:

- **Skills and MCP orchestration:** Guide agents with reusable skills and connect them to tools and external services through the Model Context Protocol (MCP).
- **Sequential workflows:** Guide agents through a predefined sequence of steps to complete a task.
